# ------------------------------------------------------------
# WHAT IS THE GROUND TRUTH?
# ------------------------------------------------------------

# Imagine the real world.

# Somewhere in reality there exists a process that determines how
# the output y depends on some input features x.

# For example

# x = house size
# y = house price

# Reality "knows" how house size influences house price,
# even if humans do not.

# We call the systematic relationship

#           y = f(x)

# the ground truth function.

# This does NOT mean

# • humans know f(x)
# • f(x) has a simple equation
# • f(x) is necessarily quadratic, linear, etc.

# It simply means

# "there exists some underlying relationship between x and y."

# ------------------------------------------------------------

# Unfortunately, we never get to observe reality perfectly.

# We collect data.

# x1,y1
# x2,y2
# x3,y3
# ...

# But our observations are always imperfect.

# Why?

# Because there are two unavoidable limitations.

# ------------------------------------------------------------
# Limitation 1
# We never observe every feature affecting y.
# ------------------------------------------------------------

# Suppose we predict exam scores.

# Our feature is

# x = hours studied

# But exam score also depends on

# • sleep
# • stress
# • intelligence
# • luck
# • question difficulty
# • health
# • motivation

# and many more.

# We didn't measure these.

# Therefore our feature vector x is incomplete.

# ------------------------------------------------------------
# Limitation 2
# Even the features we DO measure are imperfect.
# ------------------------------------------------------------

# Reality is messy.

# Measurements contain

# • sensor error
# • human error
# • rounding
# • recording mistakes
# • uncertainty

# Therefore our observations are never perfect.

# ------------------------------------------------------------

# Because of these two limitations,

# the real-world process is better written as

#           y = f(x) + ε

# where

# f(x)
# -----
# systematic, predictable relationship

# ε
# -----
# everything affecting y that is NOT explained by
# the measured features.

# This includes

# • hidden variables
# • randomness
# • measurement error
# • uncertainty

# ------------------------------------------------------------

# Notice something important.

# We NEVER directly observe

#           f(x)

# We only observe

#           y = f(x) + ε

# For example,

# suppose

#           f(7) = 49

# but

#           ε = +4

# then our dataset records

# x   y
# 7   53

# NOT because

#           f(7)=53

# but because

#           53 = 49 + 4

# The dataset stores the noisy observation,

# not the clean output of the underlying function.

# ------------------------------------------------------------

# Therefore,

# the dataset is NOT the ground truth.

# The dataset is evidence about the ground truth.

# More precisely,

# it is a finite, noisy sample generated by the underlying
# data-generating process.

# ------------------------------------------------------------

# Why is the dataset only a sample?

# Because reality contains infinitely many possible inputs.

# Even if

# x = house size

# then possible values include

# 1000 sqft
# 1000.1 sqft
# 1000.01 sqft
# 1000.001 sqft

# ...

# infinitely many values.

# We can only collect finitely many observations.

# Therefore,

# the dataset is always only a tiny sample of reality.

# ------------------------------------------------------------

# This leads to an important distinction.

# PRACTICAL MACHINE LEARNING

# The labels in the dataset are called

# "ground truth labels"

# because they are the targets we train against.

# They are the only supervision available.

# ------------------------------------------------------------

# STATISTICAL MACHINE LEARNING

# Those labels are NOT the clean outputs f(x).

# They are noisy observations

#           y = f(x) + ε

# of an unknown underlying function.

# ------------------------------------------------------------

# So what does a machine learning model actually learn?

# It does NOT try to learn ε.

# ε is random from the model's perspective.

# If ε were predictable from x,

# then it would simply become part of f(x).

# Instead,

# the model tries to approximate only

#           f(x)

# because this is the only part that consistently
# relates x to y.

# ------------------------------------------------------------

# In statistics,

# f(x) is often interpreted as

#           E[Y | X=x]

# which means

# the expected (average) output for a given input.

# Our model therefore tries to learn

#           ŷ ≈ f(x)

# rather than memorizing every noisy observation.

# ------------------------------------------------------------

# FINAL PICTURE

#                 REALITY
#
#        underlying relationship
#
#              f(x)
#                │
#                │
#     hidden variables, randomness,
#     measurement error, uncertainty
#                │
#                ▼
#
#          y = f(x) + ε
#                │
#                ▼
#
#      finite observed dataset
#                │
#                ▼
#
#      machine learning model
#                │
#                ▼
#
#      approximates f(x)
#
# NOT ε.
#
# That is the entire objective of supervised learning.
